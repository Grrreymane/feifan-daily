## 🔥 今日深度推荐 Deep Reads

### 1. Simon Willison —— 别做分类，让它幻觉吧

- **发布方**：Simon Willison's Weblog
- **链接**：<https://simonwillison.net/2026/Aug/14/dont-classify-hallucinate/>
- **作者**：Simon Willison · 2026-08-14

Doug Turnbull 提出的 HyDE（Hypothetical Document Embeddings）思路被 Simon Willison 系统整理成一份工程指南。核心反常识：面对"从 1856 个既有标签里选一个"的分类任务，与其把标签表塞进 prompt 让 LLM 匹配，不如让模型**先无视标签表直接幻觉出一个标签词**，再用向量嵌入把这个幻觉映射回真实标签集合。这套流程绕开了 prompt 上下文爆炸和长尾分布不均问题，把 LLM 的"幻觉"从缺陷转成特征。

**为什么值得读**：这是当前 RAG 与分类工程的一次范式变化，值得所有做检索、标签系统、内容审核管线的同学看。你会重新思考"如何用好一个有幻觉倾向的模型"——不是压制它，而是把它接到嵌入检索的合适位置上。

### 2. Working with AI Feels More Like Leadership Than Coding

- **发布方**：Allen Bargi's Notes
- **链接**：<https://allen.bargi.org/notes/working-with-ai-feels-like-leadership/>
- **HN**：<https://news.ycombinator.com/item?id=49299xxx> · ⬆️160 💬114

作者复盘了自己从"用 AI 写代码"过渡到"带一支 AI 团队"的心智转型。他发现关键动作从"写 prompt"变成了"分派任务、审阅结果、纠偏返工、复盘沉淀"，跟带一个初级工程师团队几乎一模一样。文章给出了一份具体的"AI 协作 leadership 检查表"——包括如何写清任务边界、如何设置验收标准、如何在 AI 失败时不直接接管而是引导它。

**为什么值得读**：资深工程师身份转型的一个清晰锚点。如果你已经开始每天开多个 Claude Code / Cursor 会话并行工作，这篇能帮你看清"能力天花板"的位置——不是模型的问题，是你还没学会当一个好 leader。

## ✍️ 今日寄语

Karpathy 在 X 上说未来几年大模型前沿"尤其具有塑造性"——这话的另一面是：**边界正在被少数几十个人推着走**。作为工业界从业者，我们不必身处那个边界，但需要理解那里发生了什么，才不会在自己的赛道上被误伤或错过时机。今日的 Simon Willison HyDE 一文之所以值得读，就是这个原因——**它示范了如何把边界处的新范式，翻译成中层工程师明天就能用的具体做法**。
