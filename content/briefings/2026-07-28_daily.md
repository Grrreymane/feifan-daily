## 🔥 今日深度推荐 Deep Reads

### 1. Simon Willison · Token 转售灰色市场深度调查

**[An Inside Look at the Relay Market Powering Token Resellers and Fraud](https://simonwillison.net/2026/Jul/26/relay-market/)** — Simon Willison 转载 Matt Lenhard 长文

Matt Lenhard 深入调查了 LLM Token 转售市场的完整生态：主要玩家集中在中国，通过池化被盗或滥用的 API Key 做 LLM 中转代理，向下游卖家提供 30%~70% 的折扣。文章拆解了 Relay 市场的三层结构——Key 抓取者、池化 Relay 运营商、面向终端开发者的白牌零售平台，并展示了 OpenAI、Anthropic、Google 等厂商对这类"暗池"的追踪与反制。

**为什么值得读**：这是 2026 年少有的把 LLM 供应链黑色经济讲清楚的一手报道。对每一个用 API 做产品的团队都是必读——你的 Key 一旦泄漏，就会以 discount 形式流回市场；也说明为什么大厂在推行 fine-grained key、usage anomaly detection、mandatory rotation。

### 2. Andrej Karpathy · 从 Vibe Coding 到 Agentic Engineering

**[Andrej Karpathy · Sequoia Ascent 2026 演讲](https://www.youtube.com/results?search_query=Andrej+Karpathy+Sequoia+Ascent+2026)**

Karpathy 在 Sequoia Ascent 2026 上给出了他对 AI 编程范式跃迁的最新判断：**Vibe Coding（凭感觉调 AI 写代码）正在被 Agentic Engineering（工程化的 Agent 编排）取代**。他系统对比了两代范式在"确定性、可审计性、上下文管理、错误恢复"上的差异，并预测未来 12-18 个月工程工作流将围绕"以 Agent 为一等公民"重构 IDE、CI、评审、测试链条。

**为什么值得读**：Karpathy 一贯把"下一代范式的分水岭"讲得最清楚。对于每天在 Cursor / Claude Code / 各类 subagent 之间切换的开发者，这场演讲提供了一个可以直接用来对齐团队的心智模型。搭配 Simon Willison 关于 subagent 成本优化的实践笔记食用效果更佳。

**[PSA: Your Dynamic Nav Mesh is killing your frame rate](https://www.reddit.com/r/unrealengine/comments/1v7rwsa/psa_your_dynamic_nav_mesh_is_killing_your_frame/)** — r/unrealengine
