## 🔥 今日深度推荐 Deep Reads

### 1. Simon Willison ｜ Anthropic 单季突破 $65bn ARR，Claude Code 贡献超 30%

**[👉 原文链接](https://simonwillison.net/2026/Aug/24/anthropic-65bn/)**

Simon Willison 汇总了 Anthropic 最新披露的关键数据：ARR 达到 $65B，其中 **Claude Code 单条产品线贡献超过 30%**。这是第一次让「AI 编程助手」作为独立利润中心被市场完整认可。文章拆解了三条曲线：API 调用量、企业席位、CLI 工具使用时长。三条线在过去 4 个季度呈现出耦合上升——单价并未大幅上涨，但客户 stickiness（单用户日均使用时长）翻了 2.4 倍。

**为什么值得读**：验证了 AI 编程工作流的商业化闭环，Claude Code 从"实验性 CLI"成长为核心营收产品，是判断"AI 编程是否只是 hype"的第一手数据。对做美术工具链、Agent 产品的人也有借鉴意义——**产品的黏性来自"每天多用几小时"，而不是"一次性付费"**。

### 2. GDC 2026 议程亮点 ｜ CAPCOM RE ENGINE 首次把实时 Path Tracing 推进 AAA 主线

**[👉 官方议程页](https://schedule.gdconf.com/session/real-time-path-tracing-in-re-engine-for-resident-evil-requiem-and-pragmata/)**

《生化危机 Requiem》和《PRAGMATA》均已在 RE ENGINE 里落地实时 Path Tracing。这场分享会拆解 CAPCOM 如何在保持 **60fps 目标**下把 PT 从技术 demo 推到量产管线：denoiser 选型策略、DLSS 4.5 Ray Reconstruction 与自研混合方案的取舍、材质响应改造成本。CAPCOM 是**首个把 PT 做进主线 3A 恐怖游戏**的团队，这条经验对国内头部工作室的下一代引擎迭代有直接参考价值——尤其是"如何把 PT 从 marketing spec 做成美术管线里稳定可用的工具"这一环。

**为什么值得读**：AAA 项目 PT 落地实操细节稀缺，绝大多数分享还停留在技术白皮书阶段。CAPCOM 这次会给出预算表、bug 案例、和美术协作的工作流细节，是判断"什么时候该切 PT 管线"的关键决策输入。

## 💬 社区热议 Community Buzz

### 🔥 Paul Graham：如果我 17 岁，我会学「如何从零构建 LLM」

**[👉 HN 讨论](https://news.ycombinator.com/)**

PG 的一句话点评在 HN 引爆了千楼讨论。他认为下一代技术的核心竞争力在于「能从底层看懂 transformer 的人」——而非 API 调用者。评论区分裂成两派：

- **支持派**：底层理解是必要护城河，仅会调 API 的人未来 3 年会被更年轻的 prompt engineer 替代。
- **反对派**：这是精英主义误导，绝大多数产品价值来自"如何把 AI 嵌进业务"，而不是"如何训练 AI"。

最精彩评论：*"PG 说的对，但他忘了自己在 1995 年也说过'学 Lisp'。10 年后，会用 Lisp 的人做出了 Y Combinator，会调 REST API 的人做出了 Stripe。Both won."*

**为什么值得关注**：这个辩论直接影响个人学习曲线的选择——特别是对处于职业转型期的从业者（含美术转 TA、TA 转 AI 应用工程师的人）。

### 🎨 KitBash 收购 ArtStation + Sketchfab：AI 训练政策成焦点

**[👉 Creative Bloq 报道](https://best-games.io/game-daily/2026-08-12)**
