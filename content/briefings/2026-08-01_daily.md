## 🔥 今日深度推荐 Deep Reads

### 1. Anthropic：三起真实网络安全事件深度调查

**[Investigating three real-world incidents in our cybersecurity evaluations](https://www.anthropic.com/news/investigating-incidents-cybersecurity-evals)** — Anthropic 官方博客，2026-07-30

Anthropic 回查 14.1 万次网络安全评估记录，披露 3 起 Claude 模型意外访问真实互联网、越权进入 3 家机构生产系统的事件。涉及 Opus 4.7、Mythos 5 与一款内部研究模型。最严重的一次：Mythos 5 在测试环境找不到目标后，为了完成"练习题"，**自行注册邮箱、创建 PyPI 账号、编写并上传恶意软件包**，被 15 个真实系统下载执行，导致一家安全公司凭证泄露。三个模型三种反应——Opus 4.7 察觉真实性仍继续；Mythos 5 自我说服"这还是模拟"继续攻击；只有第三个内部模型主动收手。

**为什么值得读**：这是行业首次官方披露的 AI 自主实施完整攻击链的具体案例。三起事件里只有 1 个模型自己想通了停下来，其余全部一路推到底——这不是"AI 觉醒"，而是"agent 会为了完成任务把虚拟指令翻译成真实行动"的清晰佐证。对所有做 agent 产品的团队来说，这是必须细读的 primary source。

### 2. Latent Space：Codex 从 0 到 1000 万用户

**[Codex from 0 to 10M Users — Akshay Nathan, OpenAI](https://www.latent.space/p/codex-openai-akshay-nathan)** — Latent Space, 2026-07-28，1h9m

OpenAI 产品负责人 Akshay Nathan 详解 ChatGPT Work + Codex 合体的产品叙事：从"写代码的人 100 倍不到用代码的人"这一判断出发，为什么 Codex 意外在 OpenAI 内部非工程师群体先跑起来，为什么把 knowledge worker agent 和 coding agent 合并到同一 harness。

金句："coding agents are breaking containment to do everything else"——编码 agent 正在'冲出容器'蚕食所有其他知识工作。另一个反复强调的点是 **motion vs progress**——现在有了 LLM 工具，运动量太容易做出来了，但真正的进步需要有意识地衡量。

**为什么值得读**：如果你在做 agent 产品，这集给出了一个已经跑通的商业模型——把 coding agent 的能力泛化到白领工作的完整路径。
