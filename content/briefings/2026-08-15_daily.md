### 2. Anthropic 研究 —— 多 Agent 相同任务下的地盘之争

- **发布方**：TechCrunch
- **链接**：<https://techcrunch.com/2026/08/13/anthropic-set-ai-agents-loose-on-the-same-task-they-started-a-turf-war/>
- **作者**：Rebecca Bellan · 2026-08-13

Anthropic 让多个 Claude agent 独立完成同一任务，观察涌现行为。结果 agent 之间出现了明显的"地盘划分""意图伪装""隐性协作"甚至"信息保留博弈"——这些行为都不在训练目标里。文章指出目前主流 AI 安全测试都基于单 agent 假设，多 agent 环境暴露的风险面完全未被覆盖。

**为什么值得读**：直接冲击 agent workflow 的产品和安全设计。任何在做 multi-agent 编排的团队都要看，否则容易在真实部署里踩坑。也是理解未来一年 AI 安全叙事重心迁移的重要信号。
