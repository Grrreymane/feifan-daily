## 🔥 今日深度推荐 Deep Reads

### 1. Simon Willison · More than just code review

> 「用好 coding agent 的关键不是逐行审阅代码，而是构建"如何指令 + 如何验证"的双向能力——审阅只是众多验证手段之一。」

Simon 这篇是对最近社区一直在争的话题——AI 编程时代到底该不该逐行看代码——给出了一个更成熟的框架。他把 code review 从中心位置移开，重新放回众多验证手段之一（测试、类型检查、审计日志、staging 环境验证……）。核心观点是：如果你只把精力花在盯着 diff 一行行看，说明你还没进入"指挥 agent"的阶段。这对每天让 Claude Code / Codex 帮你写 pipeline 脚本、shader、build tool 的技术美术尤其相关——审阅要审，但更要问：我怎么验证它没出错。

配合今天 GitHub 上 Superpowers 框架（一天 27.6 万 star）、AWS aws-bench、LinkedIn 多 agent code review 的动态一起读，能看到整个行业从"AI 会不会写代码"转向"AI 的产出该怎么被 verify"。

🔗 [simonwillison.net/2026/Aug/22/more-than-just-code-review](https://simonwillison.net/2026/Aug/22/more-than-just-code-review/)

### 2. 80 Level · Building a Hero Garment From Real-World Data

> 「Render Ready 团队分享如何用真实服装扫描 + 定制姿态假人代替传统数字布料模拟，直接跳过物理仿真环节生产影视级 hero garment。」

对 3D 服装 / 影视级资产制作有兴趣的可以细读。传统流程做一件电影级角色的英雄服装，往往要靠 Marvelous Designer 里从 2D pattern 起手做布料仿真，再传去 Substance / ZBrush 补细节。Render Ready 直接反其道——把真实服装做高精度摄影测量扫描，然后用一套可编程的定制假人姿态去驱动扫描数据，跳过所有 cloth simulation。文章讲得很干货：怎么处理扫描的接缝、怎么保留服装的自然褶皱、怎么让静态数据在动画角色身上不"塌"。对研究 UE/Unity 服装 pipeline 的 TA 是难得的真实工作流案例。

🔗 [80.lv/articles/building-a-hero-garment-from-real-world-data](https://80.lv/articles/building-a-hero-garment-from-real-world-data/)
