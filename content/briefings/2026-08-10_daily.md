## 🔥 今日深度推荐

### 1. Simon Willison：Claude Code 的 Auto Mode 已成为默认

[🔗 simonwillison.net · 08-08](https://simonwillison.net/2026/Aug/8/auto-mode-claude-code/)

Anthropic 悄悄把 Claude Code 的 auto mode（自主执行模式）从实验性开关切换为默认。新装 CLI 会直接进入 auto 模式——用户不再需要主动开启 `--auto`，AI 会自己决定何时读文件、跑命令、发提交。

Simon 分析这个信号：Anthropic 认为「AI 主动执行」已经足够稳定，可以让绝大多数用户直接使用。这与 Cursor 的 agent mode 走的是同一条路。对用 Claude 生态的开发者而言，意味着未来提示词的写法要转向「更清晰的意图声明 + 更严格的权限边界」，而非「一步步告诉它怎么做」。

**为什么值得读**：AI 编码工具的默认交互范式转变，直接影响你写 prompt 的方式。

### 2. SEED（EA 内部研发部门）：AI NPC 不是「更聪明的敌人」，而是「陪玩家演戏的伙伴」

[🔗 80.lv · 08-06](https://80.lv/articles/how-seed-is-shaping-ai-controlled-npcs-of-the-future/)

EA SEED 部门负责人 Jonas Åberg 首次公开谈 AI NPC 的产品定位。核心观点颠覆了行业既有假设——过去十年 AI NPC 的追求都是「更聪明、更难打」，但 SEED 认为方向错了：玩家不需要能虐自己的对手，而是需要**能进入剧情、能记住关系、能陪你演一段戏的伙伴**。

技术上他们用 LLM 驱动 NPC 的对话与决策链，但更关键的是在训练时喂入了大量剧本、即兴表演脚本，让模型学会「配合玩家而非碾压玩家」。EA 已经把这套框架应用到内部实验性项目。

**为什么值得读**：AI × 游戏工业级落地的信号。未来做的角色可能不再是被脚本驱动，而是每一次都在临场表演——**角色设计的表情谱、动作库、语气谱都要重新思考**。
